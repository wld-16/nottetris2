# Port of nottetris2 for the PSVita
Runs on LÖVE 0.7.2
Ported with the help of lpp-vita


The Repository contains two licenses, the sources and assets under res/ are licensed as MIT while under src/ are licensed as GNU GPL.

## Known issues

- Music does not work reliably
- Playing a Game A more than two or three times causes the game to crash
- Multiplayer does not work
